# BONK!

A Minecraft mod by **NolanLaBanane415**.

- Minecraft: 26.3
- Loader: NeoForge 26.3
- Java: 25
- Mod ID: `bonkmod`
- Version: `1.0.0`

## Build

Run `gradle build` with Java 25 and Gradle 9.2 or newer. The built JAR is written to `build/libs/`.

The first scaffold registers the BONK! Hammer and a dedicated creative tab. Hammer behavior, custom textures, sound, combo effects, commands, and the cow rocket feature will be implemented and tested in follow-up steps.
